# PC Spec Check

自動檢查瀏覽器可提供的電腦規格資訊與資訊評估。

## GitHub Pages
Repository: https://github.com/nidcjybh3rv5-web/pc-spec-check

發布方式：Settings → Pages → Deploy from a branch → main → /(root) → Save。

## 限制
一般瀏覽器無法完整取得 CPU/GPU 型號、硬碟資訊或硬體溫度；本網站的分數僅依據瀏覽器可公開的資訊做簡單評估，不代表正式硬體效能。頁面本身不會主動傳送到外部服務，但 GitHub Pages 主機仍可能收到一般訪問資訊。
